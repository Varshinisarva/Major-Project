# Major-Project
"Enhancing Wildlife Monitoring: A Hybrid Deep Learning Approach for Real-Time Animal Activity Detection and Alert Generation"
In response to growing human-wildlife conflicts and biodiversity threats, this project introduces a hybrid deep neural network model combining VGG-19 and Bidirectional LSTM (Bi-LSTM) networks for effective wildlife monitoring. 
Utilizing multiple benchmark datasets, the system achieves high recognition accuracy through techniques like data augmentation and fine-tuning. 
Designed to process real-time video feeds, it detects animal presence and sends location-based alerts to forest officers, aiming to reduce conflicts and support conservation efforts.
